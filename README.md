### Таблица сборки и запуска

| Язык        | Версия / Инструмент      | Команда сборки / запуска                          |
|-------------|--------------------------|---------------------------------------------------|
| C           | GCC                      | `gcc -Wall -Wextra -pedantic main.c -o main`     |
| C++         | G++                      | `g++ -Wall -Wextra -pedantic main.cpp -o main`   |
| Python      | Python 3                 | `python main.py`                                  |
| JavaScript  | Node.js                  | `node main.js`                                    |
| TypeScript  | tsc + Node.js            | `tsc main.ts && node main.js`                     |
| Java        | JDK                      | `javac Main.java && java Main`                    |
| C#          | .NET SDK                 | `dotnet run`                                      |
| F#          | .NET SDK                 | `dotnet run`                                      |
| Go          | Go                       | `go run main.go`                                  |
| Rust        | rustc                    | `rustc main.rs -o main && ./main`                 |
| Bash        | Bash / Git Bash          | `bash main.sh`                                    |
| Prolog      | SWI-Prolog               | `swipl -q -s main.pl -g main -t halt`             |
| Assembler   | GNU as + GCC (x86-64)    | `as main.s -o main.o && gcc main.o -o main`       |
